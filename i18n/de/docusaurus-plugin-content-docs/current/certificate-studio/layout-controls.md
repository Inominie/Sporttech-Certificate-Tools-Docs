# Layout bearbeiten {/* #layout-controls */}

Certificate Studio bietet visuelle Werkzeuge zum Positionieren der Elemente einer Vorlage.

## Elemente {/* #items */}

Die Arbeitsfläche kann Folgendes enthalten:

- Platzhalterfelder.
- Feste Texte.
- Medien und Grafiken.

## Positionierung {/* #positioning */}

Verschiebe ausgewählte Elemente direkt auf der Arbeitsfläche. Für eine genaue Platzierung stehen schrittweises Verschieben sowie Werkzeuge zum Ausrichten, Verteilen und Arbeiten mit einem Raster zur Verfügung.

## Textgestaltung {/* #text-styling */}

Für Textelemente kannst du Folgendes festlegen:

- Schriftfamilie.
- Schriftgröße.
- Ausrichtung.
- Schriftstärke.
- Schriftstil.
- Unterstreichung.

## Rückgängig und Wiederholen {/* #undo-and-redo */}

Nutze beim Bearbeiten einer Vorlage die üblichen Tastenkombinationen des Betriebssystems zum Rückgängigmachen und Wiederholen:

- macOS: `Command+Z`, `Command+Shift+Z`
- Windows: `Ctrl+Z`, `Ctrl+Shift+Z`
