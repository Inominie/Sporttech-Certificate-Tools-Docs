# Layout bearbeiten {/* #layout-controls */}

## Elemente {/* #items */}

Das Studio unterstützt Fixtexte, Platzhalter, kombinierte Texte, Bilder und Rechtecke. Eingefügte Texte erscheinen sichtbar nahe der Seitenmitte und sind zur Bearbeitung ausgewählt. Verwenden Sie die Elementauswahl, wenn ein Element auf der Arbeitsfläche schwer erreichbar ist.

Wählen Sie mehrere Felder mit **Umschalt-Klick**. Der Eigenschaftenbereich bietet dann gemeinsame Formatierungen wie Schrift, Größe, Fett und Kursiv, ohne für alle Felder eine gemeinsame Datenzuordnung oder Position vorzutäuschen.

## Positionierung {/* #positioning */}

Verschieben Sie Felder durch Ziehen und ändern Sie ihre Größe über die Eckgriffe. Im Eigenschaftenbereich stehen, soweit anwendbar, genaue Geometriewerte bereit. Horizontale Zentrierung zentriert den Text innerhalb seiner Breite; die vertikale Ausrichtung Mitte zentriert ihn zusätzlich von oben nach unten.

Richten Sie unter **Anordnen** ausgewählte Zeilen an ihren linken Kanten, Mittelpunkten oder rechten Kanten aus und legen Sie den Zeilenabstand fest. Prüfen Sie, ob eine Funktion die Auswahl untereinander oder an der Seite ausrichtet. Das sind unterschiedliche Vorgänge.

Gruppieren erhält eigenständige Felder, die gemeinsam bewegt werden können. Kombinieren macht daraus ein Textfeld; siehe [Platzhalter](placeholders.md). Eine [Layoutbox](layout-boxes.md) ordnet Zeilen automatisch an, wenn sich ihre Inhalte ändern.

## Textgestaltung {/* #text-styling */}

Legen Sie Schrift, Größe, Schriftschnitt, Kursiv, Farbe, Ausrichtung und Zeilenabstand im Eigenschaftenbereich fest. Zeilenumbrüche bearbeiten Sie im Fixtexteditor. Eine andere Schrift kann den Umbruch verändern; prüfen Sie deshalb Arbeitsfläche und erzeugtes PDF.

Systemschriften werden in geteilten Vorlagen über den Familiennamen referenziert. Lesen Sie vor dem Teilen mit einem anderen Verein den Abschnitt [Schriften auf einem anderen Computer](sharing-templates.md#fonts-on-another-computer).

## Rückgängig und Wiederholen {/* #undo-and-redo */}

Verwenden Sie Rückgängig und Wiederholen für Bearbeitungsschritte. Mehrfachformatierungen gelten gemeinsam für die Auswahl. Speichern Sie das fertige Layout; beim Wechseln oder Verlassen mit ungespeicherten Änderungen erscheint die Auswahl zum Speichern oder Verwerfen.

## Bilder und Hintergründe {/* #images-and-backgrounds */}

Mit der Platzierungs-/Sperreinstellung legen Sie fest, ob ein Bild vor oder hinter Text liegt und bearbeitbar oder gesperrt ist. **Hintergrund · gesperrt** verhindert, dass ein großes Hintergrundbild versehentlich durch einen Klick auf der Arbeitsfläche ausgewählt oder verschoben wird. Über die Elementauswahl können Sie es später auswählen und entsperren.

Über **Bild speichern…** beim ausgewählten Bild speichern Sie diese Bilddatei separat für ein anderes Design. Exportiert wird die Bilddatei, kein Bildschirmfoto der ganzen Urkunde. Die [Vordruck-Option](preprinted-paper.md) bestimmt unabhängig davon, ob das Bild in erzeugten PDFs enthalten ist; Sperren allein verhindert den Druck nicht.
