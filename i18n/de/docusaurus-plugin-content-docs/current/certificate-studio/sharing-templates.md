# Studio-Vorlagen teilen und sichern {/* #share-and-back-up-studio-templates */}

Ein Paket im Format `.sct-template` ist die übertragbare Version eines fertigen Studio-Designs. Es unterscheidet sich von einem PDF-/Word-Muster und von einem erzeugten Urkunden-PDF.

## Exportieren und importieren {/* #export-and-import */}

1. Speichern Sie die Vorlage. Exportiert wird der gespeicherte Stand, nicht ungespeicherte Änderungen auf der Arbeitsfläche.
2. Wählen Sie **Exportieren** in den Vorlagenaktionen und bewahren Sie das Paket als Sicherung auf oder teilen Sie es mit einem anderen Verein.
3. Wählen Sie auf dem Zielcomputer **Studio-Vorlage importieren**, öffnen Sie das Paket und bestätigen Sie Namen und Kategorie.
4. Bearbeiten Sie Schrift- oder Zuordnungshinweise, prüfen Sie typische Einträge in der Vorschau und speichern Sie.

## Inhalt des Pakets {/* #what-the-package-includes */}

| Enthalten | Nicht enthalten |
| --- | --- |
| Seitengröße, Elementpositionen, Texte und Formatierungen | Geladene Wettkampfeinträge und Ergebnisse |
| Platzhalternamen, Zuordnungen und kombinierte Texte | Manuelle Eventkorrekturen und Druckauswahl |
| Bilder, Hintergründe und Vordruck-Markierungen | Erzeugte oder gespeicherte PDFs und Druckverlauf |
| Sichtbarkeitsregeln und Layoutboxen | App-Einstellungen und Druckerkalibrierung |
| Schriftreferenzen; gegebenenfalls früher eingebettete Schriften | Gewöhnliche Systemschriftdateien in neu erstellten Vorlagen |

Fixtexte und Bilder können noch Namen oder andere persönliche Informationen aus dem Gestaltungsmuster enthalten. Prüfen Sie diese vor dem Teilen. Ein Paket sichert eine Vorlage, nicht die gesamte App.

## Schriften auf einem anderen Computer {/* #fonts-on-another-computer */}

Neue Vorlagen speichern die gewählte Schriftfamilie, statt die Systemschriftdatei weiterzugeben. Ist die Schrift auf dem Zielcomputer installiert, verwendet die App sie. Fehlt sie, fordert der Import zur Auswahl eines verfügbaren Ersatzes auf. Die mitgelieferte Liberation Sans ist eine übertragbare Option.

Eine Ersatzschrift oder eine andere Version derselben Schrift kann Umbrüche und Abstände verändern. Prüfen Sie nach dem Import lange Texte, kombinierte Felder und Layoutboxen. Ältere Pakete mit eingebetteten Schriften werden weiterhin unterstützt; das bedeutet nicht, dass neue Pakete alle ausgewählten Schriften einbetten.

## Kompatibilität über Versionen hinweg {/* #compatibility-over-time */}

Pakete und Vorlagendokumente besitzen Formatversionen. Unterstützte ältere Formate werden beim Laden in neueren Apps migriert. Benötigt ein Paket ein neueres, noch nicht unterstütztes Format oder eine Funktion, aktualisieren Sie die empfangende App, statt Versionsnummern zu ändern oder Felder zu entfernen.

Bewahren Sie ursprüngliche Exportpakete als Sicherung auf und prüfen Sie sie beim Wechsel auf eine neue App-Version. Unterstützte historische Formate werden kompatibel gehalten; eine zukünftige Vorlage lässt sich nicht garantiert in einer älteren App öffnen. Siehe [aktuelle Einschränkungen](../reference/current-limitations.md).
