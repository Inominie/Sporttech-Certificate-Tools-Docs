# Für vorgedrucktes Papier gestalten {/* #design-for-preprinted-paper */}

Verwenden Sie einen Scan oder ein Bild des vereinseigenen Urkundenvordrucks als Gestaltungshilfe. Die App kann diese Grafik im Studio zeigen und zugleich aus allen erzeugten PDFs weglassen.

## Referenzgrafik einrichten {/* #set-up-reference-artwork */}

1. Fügen Sie das Papierbild hinzu oder wählen Sie die aus dem Gestaltungsmuster importierte Grafik.
2. Passen Sie Position und Größe an die Urkundenseite an.
3. Wählen Sie **Hintergrund · gesperrt**, um versehentliches Verschieben zu verhindern.
4. Aktivieren Sie für dieses Bild **Bereits auf dem Papier vorgedruckt**.
5. Platzieren Sie Namen, Ergebnisse und weitere Inhalte in den freien Bereichen und speichern Sie die Vorlage.

Sperre und Vordruck-Markierung erfüllen unterschiedliche Zwecke: Die Sperre schützt die Geometrie; die Markierung steuert die PDF-Ausgabe. Besteht der Vordruck aus mehreren Bildern, markieren Sie jedes betreffende Bild.

## Was in welcher Ansicht erscheint {/* #what-each-view-shows */}

| Ansicht oder Ausgabe | Referenzgrafik |
| --- | --- |
| Studio-Arbeitsfläche und Vorlagenminiatur | Zur Gestaltung sichtbar. |
| Erzeugte PDF-Vorschau einschließlich Studio-PDF-Tests | Ausgelassen. |
| Gespeichertes oder gedrucktes PDF | Ausgelassen. |
| Exportierte Studio-Vorlage | Grafik und Vordruck-Einstellung bleiben erhalten. |

Dies ist keine PDF-Ebene, die ein Drucker wahlweise ignorieren kann. Die Grafik fehlt im PDF selbst; dadurch ist das Verhalten bei unterschiedlichen PDF-Anzeigen und Druckern einheitlich.

## Vor dem Drucken {/* #before-printing */}

Legen Sie den passenden Vordruck ein und prüfen Sie ein einzelnes Testblatt mit der richtigen Skalierung. Nutzen Sie die [Druckkalibrierung](../produce/print-calibration.md) für einen Druckerversatz. Produzieren weist darauf hin, wenn die gewählte Vorlage vorgedrucktes Papier voraussetzt.

Für eine vollständige digitale Urkunde mit Grafik erstellen Sie eine Kopie der Vorlage und deaktivieren **Bereits auf dem Papier vorgedruckt** bei deren Referenzbildern. Prüfen Sie diese Kopie vor dem Teilen des PDFs.
