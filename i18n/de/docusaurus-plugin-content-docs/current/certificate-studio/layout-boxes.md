# Layoutboxen für unterschiedliche Teamgrößen {/* #layout-boxes-for-variable-team-sizes */}

Eine Layoutbox hält mehrere Textzeilen in einem festgelegten Bereich. Das ist etwa für Teammitgliedernamen sinnvoll: Sechs mögliche Namen teilen sich einen Bereich, ohne bei kleineren Teams störende leere Plätze zu hinterlassen.

## Box erstellen {/* #create-the-box */}

1. Fügen Sie die benötigten Teammitglied-Platzhalter hinzu und ordnen Sie jeden seinem eigenen Mitgliedsplatz zu.
2. Wählen Sie die Felder mit Umschalt-Klick und erstellen Sie aus der Auswahl eine Layoutbox.
3. Positionieren Sie die Box auf der Urkunde und passen Sie ihre Größe an.
4. Legen Sie Zeilenreihenfolge, Innenabstand, Zeilenabstand und Ausrichtung im Eigenschaftenbereich fest.
5. Aktivieren Sie **Leere Zeilen ausblenden** und testen Sie verschiedene Teams mit echten Daten.

Eine Layoutbox ordnet Textzeilen in einer Spalte an. Sie ist kein beliebiges Raster und kein Behälter für Hintergrundbilder.

## Layoutmodus wählen {/* #choose-a-layout-mode */}

| Modus | Ergebnis |
| --- | --- |
| Zentrierter Stapel | Zeilen behalten Schriftgröße und Abstand; der Stapel wird innerhalb der Box ausgerichtet. Geeignet für einheitliche Namen mit mehr Freiraum bei kleineren Teams. |
| Gleichmäßig verteilte Zeilen | Sichtbare Zeilen werden über die verfügbare Fläche verteilt. |
| Automatische Schriftgröße | Die Schriftgröße passt sich innerhalb der gewählten Mindest- und Höchstgröße dem verfügbaren Bereich an. |

Verwenden Sie nach Bedarf die horizontale Ausrichtung links/mittig/rechts und die vertikale Ausrichtung oben/Mitte/unten. Der Innenabstand hält Platz zum Boxrand frei; der Zeilenabstand trennt benachbarte Zeilen.

## Leere Zeilen und lange Namen {/* #empty-rows-and-long-names */}

Leere Zeilen werden anhand des ausgewählten echten Eintrags ermittelt. Im Platzhaltermodus bleiben die Namen zur Bearbeitung sichtbar. Eine Zeile mit festem Text wie „Athlet:“ ist nicht leer, nur weil der zugeordnete Name fehlt.

Lange Namen können umbrechen. Die automatische Größe schrumpft nicht unbegrenzt: Passen die Inhalte weiterhin nicht, verhindert eine Überlaufwarnung die PDF-Erstellung, statt Namen unbemerkt abzuschneiden. Vergrößern Sie die Box, verringern Sie Abstände oder passen Sie die erlaubten Schriftgrößen an.

## Bearbeiten oder auflösen {/* #edit-or-dissolve */}

Ändern Sie im Layoutbox-Eigenschaftenbereich die Reihenfolge oder fügen Sie Mitgliedszeilen hinzu bzw. entfernen Sie diese. Wählen Sie eine einzelne Zeile, wenn Sie deren Datenzuordnung ändern möchten. Beim Auflösen bleiben Felder und Zuordnungen als einzelne Elemente an ihren aktuellen Layoutpositionen erhalten. Prüfen Sie das Ergebnis vor dem Speichern.
