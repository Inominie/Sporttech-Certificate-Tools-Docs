# Vorlagenbibliothek {/* #template-library */}

Die linke Bibliothek gruppiert gespeicherte Vorlagen nach Einzel, Synchron und Team. Eine ausgewählte Vorlage wird hervorgehoben, ohne an den Listenanfang zu springen. Das Aktionsmenü der Vorlage bietet Umbenennen, Kopieren, Exportieren und Löschen.

Für jede Kategorie stehen auch mitgelieferte Starter bereit. Beim Speichern einer bearbeiteten Startervorlage entsteht eine eigene gespeicherte Vorlage; der mitgelieferte Starter bleibt verfügbar. Bei einer bereits gespeicherten eigenen Vorlage aktualisiert Speichern dieselbe Vorlage.

## Aktive Vorlage {/* #active-template */}

Sie bearbeiten die aktuell geöffnete Vorlage. **Speichern** wird bei Änderungen aktiv und speichert diese in derselben Vorlage. Es entsteht keine weitere Kopie. Ändern Sie den gespeicherten Titel über **Umbenennen** und verwenden Sie **Kopieren** für ein eigenes neues Design.

Eine gespeicherte Vorlage kann unter Produzieren für ihre passende Kategorie ausgewählt werden. Ein offener, ungespeicherter Studio-Entwurf ist nicht automatisch die gespeicherte Druckvorlage.

## Eine Vorlage importieren {/* #importing-a-template */}

Verwenden Sie **Studio-Vorlage importieren** für ein Paket im Format `.sct-template`. Wählen Sie bei der Einrichtung Namen und Kategorie, lösen Sie fehlende Schriften oder unpassende Zuordnungen auf und prüfen Sie das Ergebnis. Siehe [Vorlagen teilen](sharing-templates.md).

Verwenden Sie für PDF- oder Word-Dateien stattdessen den [Import eines Gestaltungsmusters](design-samples.md). Bei neuen Vorlagen, Mustern und geteilten Vorlagen ist jeweils eine eindeutige Kategorie vorgesehen.

## Vorlagen kopieren {/* #copying-templates */}

Wählen Sie **Kopieren**, geben Sie einen neuen Namen ein und wählen Sie eine Kategorie. Kopiert wird der gespeicherte Stand; speichern Sie aktuelle Änderungen deshalb zuerst. Das Original bleibt erhalten, auch wenn die Kopie einer anderen Kategorie zugeordnet wird.

Prüfen Sie bei einem Kategorienwechsel die Zuordnungen, die in der Zielkategorie nicht verfügbar sind. Ersetzen Sie sie oder lassen Sie sie, soweit angeboten, für die spätere Bearbeitung unzugeordnet. Prüfen Sie auch betroffene Bedingungen. Ein einzelner Athletenname steht beispielsweise nicht automatisch für alle Teammitglieder.

## Vorlagen löschen {/* #deleting-templates */}

Löschen Sie nach Prüfung der Bestätigung nur die ausgewählte Bibliotheksvorlage. Kopien bleiben eigenständige Vorlagen. Für eine übertragbare Sicherung [exportieren Sie vor dem Löschen ein Studio-Paket](sharing-templates.md).

## Ungespeicherte Änderungen {/* #unsaved-changes */}

Beim Vorlagenwechsel oder Verlassen des Studios wählen Sie **Speichern und fortfahren**, **Änderungen verwerfen** oder **Abbrechen**. Scheitert das Speichern, bleibt der Entwurf geöffnet, damit Sie den Fehler beheben können. Verlassen Sie sich nicht darauf, dass ein ungespeicherter Entwurf einen Neustart übersteht.
