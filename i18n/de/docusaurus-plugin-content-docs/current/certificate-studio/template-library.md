# Vorlagenbibliothek {/* #template-library */}

Die Vorlagenbibliothek speichert Urkundenprofile auf dem lokalen Computer.

  <figcaption>Die linke Leiste enthält die aktuelle Vorlage, gespeicherte Profile, Startvorlagen sowie die Funktion zum Hochladen oder Importieren.</figcaption>
</figure>

## Aktive Vorlage {/* #active-template */}

Die aktive Vorlage wird aktuell von Produce verwendet. Im Vorlagenwähler von Produce kannst du auch ein anderes gespeichertes Vorlagenprofil auswählen.

## Eine Vorlage importieren {/* #importing-a-template */}

Importiere eine Vorlage in Certificate Studio oder bestätige dort einen ausstehenden Vorlagen-Upload. Prüfe nach dem Import die Platzhalterzuordnung und das Seitenlayout, bevor du PDFs erzeugst.

## Vorlagen kopieren {/* #copying-templates */}

Kopiere eine vorhandene Vorlage, wenn das Layout weitgehend passt, du aber eine Variante für eine andere Wettkampfklasse, einen anderen Wettkampf oder ein anderes Urkundendesign benötigst.

## Vorlagen löschen {/* #deleting-templates */}

Wenn du eine gespeicherte Vorlage löschst, wird sie aus der lokalen Vorlagenbibliothek entfernt. Importierte Wettkampfdaten und bereits gespeicherte PDFs werden dadurch nicht gelöscht.
