# Sporttech Certificate Tools {/* #sporttech-certificate-tools */}

Sporttech Certificate Tools unterstützt Vereine dabei, aus Sporttech-Wettkampfergebnissen Urkunden, Startlisten und Ergebnislisten zu erstellen. Diese Anleitung beschreibt die aktuellen Abläufe der Beta 0.7.2 auf Deutsch und Englisch.

## Wofür die App gedacht ist {/* #what-the-app-is-for */}

Importieren Sie ein Online-Event, einen lokalen OVS-Wettkampf oder einen Sporttech-Excel-Export. Prüfen Sie die Einträge, korrigieren Sie bei Bedarf die Urkundentexte, gestalten Sie wiederverwendbare Vorlagen im Studio und erzeugen Sie PDFs zur Vorschau und zum Drucken.

Sporttech bleibt für Punkte, Platzierungen und Wettkampfgruppen zuständig. In der App lassen sich Urkundenangaben wie Namen und Vereine korrigieren; sie ist kein zweites Wertungssystem.

Gespeicherte Vorlagen sowie gespeicherte oder gedruckte PDFs bleiben nach einem Neustart verfügbar. Das geladene Event, manuelle Korrekturen und temporäre Vorschauen gehören zur aktuellen Sitzung.
