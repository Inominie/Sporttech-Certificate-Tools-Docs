# Sporttech Certificate Tools {/* #sporttech-certificate-tools */}

Sporttech Certificate Tools ist eine Desktop-App, mit der du Sporttech-Wettkampfergebnisse importieren, Wettkampfdaten prüfen, Urkundenlayouts vorbereiten und druckfertige PDFs erstellen kannst.

Die Dokumentation folgt demselben Ablauf wie die App:

1. **Event (Wettkampf)** – Lade Wettkampfergebnisse von Sporttech online, einem lokalen OVS-Server oder einer exportierten Datei.
2. **Quick Check (Datenprüfung)** – Prüfe importierte Sporttech-Wettkampfdaten, Wettkampfklassen, Warnungen, Finalergebnisse, ausgeschlossene Einträge und manuelle Korrekturen.
3. **Certificate Studio (Urkundenstudio)** – Bereite Urkundenvorlagen, Platzhalter, feste Texte und Layoutdetails vor.
4. **Produce (Ausgabe)** – Erstelle eine Vorschau von Urkunden oder Klassenlisten und speichere, drucke oder öffne die PDFs.
5. **Settings (Einstellungen)** – Passe Importverhalten, Druckkalibrierung, Diagnosefunktionen und lokale Laufzeitdaten an.

Die englischen Bezeichnungen von App-Bereichen und Schaltflächen bleiben in dieser Anleitung zur Wiedererkennung erhalten; ihre Funktion wird auf Deutsch erklärt.

## Wofür die App gedacht ist {/* #what-the-app-is-for */}

Nutze die App, wenn für einen Wettkampf Urkunden oder Ergebnislisten auf Grundlage von Sporttech-Daten benötigt werden. Sie ist für den lokalen Betrieb ausgelegt: Importierte Wettkampfdaten, Vorlagen und erzeugte PDFs bleiben auf dem Computer, auf dem die App installiert ist, sofern du exportierte Dateien oder Support-Pakete nicht selbst weitergibst.
