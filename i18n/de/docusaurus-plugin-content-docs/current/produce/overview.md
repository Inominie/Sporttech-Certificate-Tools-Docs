# Überblick: Produzieren {/* #produce-overview */}

Produzieren erstellt PDFs aus den geprüften Eventdaten. Wählen Sie Klasse oder Einträge und die Ausgabeeinstellungen und prüfen Sie vor dem Speichern oder Drucken die Vorschau.

<figure className="app-screenshot">

  <figcaption>Ausgabeeinstellungen und Vorschau stehen auf der Druckseite gemeinsam bereit.</figcaption>
</figure>

## Dokumenttypen {/* #document-types */}

- **Urkunden** verwenden eine Studio-Vorlage passend zur Eintragskategorie.
- **Startlisten** liefern eine Teilnehmerliste der Klasse.
- **Ergebnislisten** zeigen die Quellergebnisse für die gewählte Phase.

[Urkundenexemplare und Reihenfolge](certificates.md) sind Urkundeneinstellungen; sie vervielfachen keine Startlisten- oder Ergebnislistenzeilen.

## Druckbereitschaft {/* #production-readiness */}

Prüfen Sie vor der Ausgabe den ausgewählten Umfang, Warnungen und die Vorlage. Fehlende Vorlagenzuordnungen, ungeklärte Exemplarzahlen oder überlaufende Layoutboxen müssen zuerst korrigiert werden. Sporttech liefert Punkte, Platzierungen und Gruppen; falsche Ergebnisse korrigieren Sie dort und aktualisieren anschließend.

Änderungen an Auswahl oder Ausgabeeinstellungen erzeugen die Vorschau neu. Warten Sie auf das aktuelle PDF; eine frühere Vorschau bestätigt nicht die Richtigkeit neuer Einstellungen.

## Hauptaktionen {/* #main-actions */}

| Aktion | Zweck |
| --- | --- |
| PDF-Vorschau | Aktuelle Ausgabe erzeugen und prüfen. |
| PDF speichern | Das erzeugte PDF als gespeicherte Ausgabe behalten. |
| Drucken | Die aktuelle Vorschau an den Druckablauf übergeben; vorheriges Speichern ist optional. |
| PDF öffnen | Die erzeugte Datei extern öffnen. |
| Ordner öffnen | Den Ausgabeordner öffnen. |

Ein erfolgreich übergebener Druckauftrag bewahrt ebenfalls sein PDF auf. Das bloße Anzeigen oder Öffnen eines temporären PDFs macht es nicht dauerhaft. Siehe [Vorschau, Speichern und Drucken](preview-save-print.md).
