# Überblick: PDF-Ausgabe {/* #produce-overview */}

Nutze **Produce**, um Dokumentvorschauen zu erzeugen und PDFs zu speichern.

<figure className="app-screenshot">
  <img src="/Sporttech-Certificate-Tools-Docs/img/app/produce-preview.png" alt="Bereich Produce mit Ausgabeoptionen für Urkunden und einer erzeugten PDF-Vorschau" />
  <figcaption>Produce zeigt Dokumenttyp, Umfang, Vorlage, Vorschaustatus und die erzeugte PDF-Datei in einer gemeinsamen Ansicht.</figcaption>
</figure>

## Dokumenttypen {/* #document-types */}

Produce unterstützt:

- **Certificates**: Urkunden für Einzelteilnehmende, Synchronpaare oder Teams.
- **Class Lists**: druckbare Dokumente im Stil von Ergebnis- oder Startlisten.

## Bereitschaft für die Ausgabe {/* #production-readiness */}

Der Bereich Produce zeigt den Bereitschaftsstatus, die aktive Vorlage, die Anzahl der Warnungen, den ausgewählten Dokumenttyp, den Ausgabeumfang und die ungefähre Seitenzahl.

Behebe Warnungen vor dem endgültigen Druck, wenn sie den Urkundeninhalt oder das Layout betreffen.

## Die wichtigsten Aktionen {/* #main-actions */}

| Aktion | Zweck |
| --- | --- |
| **Preview PDF** | Eine temporäre Vorschau für den ausgewählten Umfang erzeugen. |
| **Save PDF** | Die aktuelle Vorschau im Ausgabeordner speichern. |
| **Print** | Die gespeicherte Vorschau über die Druckfunktion des Betriebssystems drucken. |
| **Open PDF** | Die gespeicherte PDF-Datei öffnen. |
| **Open Folder** | Den Ausgabeordner öffnen. |
