# Urkunden {/* #certificates */}

## Vorlage auswählen {/* #select-a-template */}

Wählen Sie **Urkunden** und eine gespeicherte Vorlage für die ausgewählte Kategorie: Einzel, Synchron oder Team. Öffnen Sie bei Änderungsbedarf das Studio über die Vorlagenauswahl. Speichern Sie dort Ihre Änderungen, bevor Sie zu Produzieren zurückkehren.

## Umfang wählen {/* #choose-a-scope */}

Wählen Sie den gewünschten Eintrag, mehrere Einträge, die Klasse oder einen verfügbaren größeren Umfang. Prüfen Sie vor dem Druck die Eintrags-/Seitenanzahl und ausgeschlossene Einträge. Die Vorlagenkategorie muss zu den Einträgen passen; eine Teamvorlage macht aus einem Einzeleintrag kein Team.

## Anzahl der Exemplare {/* #number-of-copies */}

**Exemplare** bietet:

| Einstellung | Erzeugte Urkunden |
| --- | --- |
| Pro Eintrag (Standard) | Eine je ausgewähltem Einzelathleten, Synchronpaar oder Team. |
| Pro Athlet | Einzel: 1; Synchron: 2; Team: eine pro Mitglied. |

Teamzahlen verwenden die gemeldete Mitgliederanzahl oder, wenn diese fehlt, die verfügbare Mitgliederliste. Die sechs möglichen Namensfelder einer Vorlage bestimmen nicht die Teamgröße. Eine gemeldete Teamgröße kann Mitglieder einschließen, deren Namen nicht geliefert wurden.

Öffnen Sie im Modus Pro Athlet **Anzahlen prüfen oder anpassen**, um automatische Werte zu prüfen oder eine ausdrückliche Anzahl von 1 bis 100 pro Eintrag einzugeben. Löschen Sie eine Überschreibung oder setzen Sie auf automatische Anzahlen zurück, um wieder den berechneten Wert zu verwenden. Fehlt die Teamgröße oder ist sie widersprüchlich, müssen Sie vor der PDF-Erstellung eine Anzahl angeben.

Exemplare eines Eintrags bleiben im PDF zusammen. Sie wiederholen denselben Urkundeninhalt; diese Option erzeugt nicht auf jeder Teamkopie einen anderen Einzelnamen. Ein PDF ist auf 10.000 Urkundenseiten begrenzt. Diese Einstellungen gelten nicht für Klassenlisten, Kalibrierungsblätter oder einzelne Nachdrucke aus dem Verlauf.

**Wählen Sie im Druckdialog ein Exemplar.** Das PDF enthält bereits die gewünschte Anzahl. Die Exemplarauswahl gehört zur Event-Sitzung, nicht zur Vorlage; bei einem anderen Event oder einer neuen Sitzung wird sie zurückgesetzt.

## Druckreihenfolge {/* #print-order */}

Wählen Sie **Erster Platz zuerst** oder **Letzter Platz zuerst**. Die Umkehr erfolgt innerhalb jeder Klasse; die Klassenreihenfolge bleibt erhalten. Einträge ohne nutzbare Platzierung folgen den platzierten Einträgen. Bei nur einem Eintrag gibt es keine sinnvolle Reihenfolge zu ändern.

Prüfen Sie nach einem Reihenfolgewechsel die erste und letzte Seite, insbesondere bei mehreren Exemplaren.

## Warnungen {/* #warnings */}

Beheben Sie vor der Ausgabe fehlende Zuordnungen, unbekannte Anzahlen oder Layoutüberläufe. Prüfen Sie Eventdatenwarnungen in Quick Check. Verwendet die Vorlage [Vordruck-Grafiken](../certificate-studio/preprinted-paper.md), lässt das PDF diese Bilder absichtlich aus; legen Sie das passende Papier ein.
