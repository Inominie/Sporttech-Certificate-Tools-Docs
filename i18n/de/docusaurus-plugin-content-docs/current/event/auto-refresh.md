# Auto-Aktualisierung {/* #auto-refresh */}

Die Auto-Aktualisierung hält das geladene Online- oder lokale OVS-Event aktuell. Sie wird unter **Einstellungen** konfiguriert, ist standardmäßig eingeschaltet und wird als Einstellung gespeichert.

## Wann sie sinnvoll ist {/* #when-to-use-it */}

Lassen Sie sie während eines Wettkampfs eingeschaltet. Die Aktualisierung desselben Events erhält manuelle Korrekturen an Namen, Vereinen und Urkundenhinweisen, gültige Auswahlen und Studio-Änderungen. Neue Punkte und Platzierungen kommen weiterhin aus Sporttech.

Das Aktualisierungssymbol in der Kopfzeile ist immer erreichbar, auch im Studio. Nutzen Sie es vor dem Druck und prüfen Sie die letzte erfolgreiche Aktualisierung. Scheitert eine Aktualisierung, behält die App die bisherigen Daten und zeigt den Fehler an; diese Daten können inzwischen veraltet sein.

## Wann sie ausgeschaltet werden kann {/* #when-to-turn-it-off */}

Bei Bedarf können Sie die automatische Aktualisierung in den Einstellungen pausieren, etwa zur Untersuchung eines Verbindungsproblems. Die manuelle Aktualisierung bleibt verfügbar. Zum Schutz von Urkundenkorrekturen müssen Sie sie nicht ausschalten.

Excel-Events werden nicht automatisch abgefragt. Wählen Sie beim [Aktualisieren eines Dateiimports](file-import.md) eine neue Arbeitsmappe aus.

## Standardintervall {/* #default-interval */}

Der Standard beträgt **30 Sekunden**. Zur Auswahl stehen 10, 15, 30, 60, 120 oder 300 Sekunden. Aktualisierungen werden mit laufenden Vorgängen und inaktiven Arbeitsbereichen abgestimmt; das Intervall garantiert keinen sekundengenauen Abruf.

Geänderte Quelldaten können eine PDF-Vorschau ungültig machen. Warten Sie vor dem Speichern oder Drucken auf die aktuelle Vorschau.
