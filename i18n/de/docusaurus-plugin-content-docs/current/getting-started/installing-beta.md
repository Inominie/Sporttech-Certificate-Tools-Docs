# Beta installieren {/* #installing-the-beta */}

Sporttech Certificate Tools wird derzeit als unsignierte Beta-Software verteilt. Installiere die App nur auf Computern, auf denen unsignierte Beta-Software zugelassen ist.

## macOS {/* #macos */}

1. Lade die aktuelle macOS-DMG-Datei vom Projektverantwortlichen oder von der Beta-Release-Seite herunter.
2. Öffne die DMG-Datei.
3. Ziehe **Sporttech Certificate Tools.app** in den Ordner **Programme (Applications)**.
4. Starte die App.
5. Falls macOS die App blockiert, öffne **Systemeinstellungen > Datenschutz & Sicherheit** und erlaube dort den Start der App.

Warnungen von macOS Gatekeeper sind bei unsignierten Beta-Versionen zu erwarten.

## Windows {/* #windows */}

1. Lade das aktuelle Windows-Installationsprogramm vom Projektverantwortlichen oder von der Beta-Release-Seite herunter.
2. Führe das Installationsprogramm aus.
3. Falls Microsoft Defender SmartScreen erscheint, wähle **Weitere Informationen > Trotzdem ausführen** nur dann, wenn die Version aus einer vertrauenswürdigen Projektquelle stammt.
4. Starte **Sporttech Certificate Tools** über das Startmenü oder die Desktop-Verknüpfung.

SmartScreen-Warnungen sind zu erwarten, solange die App nicht signiert ist und noch keine entsprechende Reputation aufgebaut hat.

## Zustand nach einer Neuinstallation {/* #clean-install-state */}

Eine neue Installation enthält weder Wettkampfdaten noch Urkundenvorlagen. Beim ersten Start ist die App leer. Importiere Wettkampfdaten und wähle oder erstelle eine Urkundenvorlage, bevor du PDFs erzeugst.
