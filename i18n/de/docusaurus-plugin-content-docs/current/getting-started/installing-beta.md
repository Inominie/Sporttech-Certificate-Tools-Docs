# Beta installieren {/* #installing-the-beta */}

Laden Sie die Installationsdateien von der [Downloadseite](https://inominie.github.io/Sporttech-Certificate-Tools-Docs/de/download) herunter. Neue Mac-Versionen mit integriertem Updater sind signiert und notarisiert. Windows-Installer bleiben unsigniert; der Computer muss ihre Installation erlauben.

## macOS {/* #macos */}

1. Wählen Sie auf der Downloadseite **Für Mac herunterladen**. Die DMG-Datei funktioniert auf Macs mit Apple Silicon und Intel.
2. Öffnen Sie die DMG-Datei.
3. Ziehen Sie **Sporttech Certificate Tools.app** in den Ordner **Programme (Applications)**.
4. Starten Sie die App.

Ältere unsignierte Betas können zusätzliche Gatekeeper-Warnungen anzeigen. Installieren Sie die neue signierte App in Programme, damit zukünftige Updates innerhalb der App möglich sind.

## Windows {/* #windows */}

1. Wählen Sie auf der Downloadseite **Für Windows herunterladen**. Verwenden Sie die EXE-Datei für Windows x64.
2. Führen Sie das Installationsprogramm aus.
3. Falls Microsoft Defender SmartScreen erscheint, wählen Sie **Weitere Informationen > Trotzdem ausführen** nur dann, wenn die Version aus einer vertrauenswürdigen Projektquelle stammt.
4. Starten Sie **Sporttech Certificate Tools** über das Startmenü oder die Desktop-Verknüpfung.

SmartScreen-Warnungen sind zu erwarten, solange die App nicht signiert ist und noch keine entsprechende Reputation aufgebaut hat.

## Zustand nach einer Neuinstallation {/* #clean-install-state */}

Eine neue Installation enthält weder Wettkampfdaten noch eigene Urkundenvorlagen. Im Studio stehen mitgelieferte Starter bereit. Beim ersten Start ist die App leer. Importieren Sie Wettkampfdaten und wählen oder erstellen Sie eine Urkundenvorlage, bevor Sie PDFs erzeugen.

Wird ein aktueller signierter Mac-Installer unerwartet blockiert, lesen Sie die [Fehlerhilfe](../troubleshooting/common-issues.md#macos-blocks-the-app), bevor Sie Sicherheitseinstellungen ändern. Bei bestehenden Installationen verwenden Sie bevorzugt [Updates in der App](../settings/checking-for-updates.md).
