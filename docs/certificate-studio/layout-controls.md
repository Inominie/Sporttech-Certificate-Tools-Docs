# Layout controls

## Items

Studio supports fixed text, placeholders, combined text, images and rectangles. Inserted text starts visibly near the page centre and is selected for editing. Use the element selector if an item is hard to reach on the canvas.

Select several fields with **Shift-click**. The inspector then offers shared formatting such as font, size, bold and italic, without pretending that all fields have one data mapping or position.

## Positioning

Drag fields to move them and use corner handles to resize their boxes. The inspector provides precise geometry where applicable. Horizontal centre alignment centres text across its box; use vertical middle alignment to centre it from top to bottom as well.

For selected rows, use **Arrange** to align their left edges, centres or right edges and set the gap between rows. Check whether an action aligns the selection to each other or to the page. These are different operations.

Grouping keeps fields separate while letting them move together. Combining turns them into one text field; see [placeholders](placeholders.md). A [layout box](layout-boxes.md) automatically arranges rows when their contents change.

## Text styling

Set font, size, weight, italic, colour, alignment and line spacing in the inspector. Use the fixed-text editor for line breaks. Text can wrap differently with another font, so inspect both the canvas and generated PDF.

System fonts are referenced by family name in shared templates. See [font handling](sharing-templates.md#fonts-on-another-computer) before sharing a layout with another club.

## Undo and redo

Use Undo and Redo for editing changes. Bulk formatting applies to the selection together. Save once the layout is ready; switching or leaving with unsaved changes prompts you to save or discard.

## Images and backgrounds

Choose the image placement/lock setting to place it in front of or behind text and make it editable or locked. **Background · locked** prevents a large background image from being selected or moved by an accidental canvas click. Use the element selector to select and unlock it later.

Use **Save image…** for the selected image to save that image asset separately for another design. It exports the asset, not a screenshot of the entire certificate. The [preprinted-paper option](preprinted-paper.md) separately controls whether the image belongs in generated PDFs; locking alone does not stop it printing.
