# Layout controls

Certificate Studio provides visual controls for positioning template items.

## Items

The canvas can include:

- Placeholder fields.
- Fixed text.
- Assets.

## Positioning

Move selected items visually on the canvas. Use nudge, alignment, distribution, and grid tools when precise placement is needed.

## Text styling

Text items can define:

- Font family.
- Font size.
- Alignment.
- Weight.
- Style.
- Underline.

## Undo and redo

Use the standard system shortcut for undo and redo while editing a template:

- macOS: `Command+Z`, `Command+Shift+Z`
- Windows: `Ctrl+Z`, `Ctrl+Shift+Z`
