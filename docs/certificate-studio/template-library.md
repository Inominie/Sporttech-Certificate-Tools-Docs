# Template library

The left library groups saved templates by Single, Synchronized and Team. Selecting a template highlights it without moving it to the top of the list. Use the template's actions menu for rename, copy, export and delete.

Built-in starters are also available for each category. Saving edits to a starter creates your own saved template; the built-in starter itself remains available. For an existing saved template, Save updates that same template.

## Active template

The open template is the one you are editing. **Save** becomes enabled when it has changes and saves those changes to the same template. It does not create another copy. Use **Rename** to change the saved title, and **Copy** when you need a separate design.

A saved template can be selected for its matching category in Produce. An open, unsaved Studio draft is not automatically the saved template used for a print run.

## Importing a template

Use **Import Studio Template** for a `.sct-template` package. Choose a name and category in setup, resolve any missing fonts or incompatible mappings, and review the imported result. See [sharing templates](sharing-templates.md).

For a PDF or Word file, use [design sample import](design-samples.md) instead. New, sample and shared-template setup all require a clear category.

## Copying templates

Choose **Copy**, enter a new name and select a category. Copying uses the saved version, so save recent edits first. The original stays intact, including when the copy uses another category.

When changing category, review mappings that are unavailable for the target category. Replace them or leave them unassigned for later editing where offered. Review any affected conditions as well. For example, an individual athlete name cannot simply stand in for all team members.

## Deleting templates

Delete only the selected library template after checking the confirmation. Copies remain separate templates. To keep a transferable backup, [export a Studio package](sharing-templates.md) before deleting.

## Unsaved changes

When you switch templates or leave Studio, choose **Save and continue**, **Discard changes** or **Cancel**. A failed save keeps the draft open so you can resolve the error. Do not rely on an unsaved draft surviving an app restart.
