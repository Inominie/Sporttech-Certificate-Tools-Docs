# Template library

The template library stores saved certificate profiles on the local computer.

<figure className="app-screenshot">
  <img src="/Sporttech-Certificate-Tools-Docs/img/app/certificate-studio.png" alt="Certificate Studio template library rail with current and starter templates" />
  <figcaption>The left rail lists the current template, saved profiles, starter templates, and the upload/import action.</figcaption>
</figure>

## Active template

The active template is the template currently used by Produce. Produce can also select a saved template profile from the template selector.

## Importing a template

Use Certificate Studio to import or confirm a pending template upload. After import, check the placeholder mapping and page layout before producing PDFs.

## Copying templates

Copy an existing template when the layout is mostly correct but needs a variation for another class type, event, or certificate design.

## Deleting templates

Deleting a saved template removes it from the local template library. It does not delete imported competition data or previously saved PDFs.
