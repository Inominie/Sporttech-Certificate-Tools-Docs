# Glossary

## Active project

The currently loaded event data and related local state in the app.

## Auto-refresh

A live import mode that reloads online or offline event data at a regular interval.

## Certificate row

One printable certificate entry, such as an individual athlete, synchronized pair, or team.

## Certificate Studio

The app section used to manage templates, placeholders, fixed text, assets, and layout.

## Class

A competition grouping used for review and printing, such as a discipline/category/gender combination.

## Class list

A PDF list generated by the app, separate from certificate pages.

## OVS

Offline venue scoring system used at events. The app can import from a reachable local OVS HTTP server.

## Placeholder

A dynamic template field that is filled from imported data during PDF generation.

## Support bundle

A ZIP file containing diagnostic data for beta support. It may contain personal or event data and should be reviewed before sharing.

## Template profile

The saved layout definition that tells the app how to render certificate content onto a page.
