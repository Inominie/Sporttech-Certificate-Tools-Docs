# Glossary

## Active project

The event data and review state loaded for the current session. It is not a permanent event archive.

## Auto-refresh

Periodic reload of the current online/OVS event. Enabled by default; preserves same-event certificate corrections.

## Certificate row

An imported entry used to produce a certificate: an individual athlete, synchronized pair or team. Multiple copies can refer to the same row.

## Certificate Studio

The editor for saved certificate templates, data mappings and layout previews.

## Class

A competition grouping from Sporttech. Class/entry selection provides the basis for checking preview data.

## Class list

A start list or result list produced with the app's list layout, rather than a certificate template.

## OVS

Sporttech's local competition system. This app connects to its running HTTP service on the event network.

## Placeholder

A text element, or part of combined text, that gets its value from a selected data source. Its editor label and data mapping are separate.

## Support bundle

A ZIP of diagnostic information that may include participant data. It is for private support and is not a full backup.

## Template profile

An older/internal name for a saved certificate template. In the current workflow, use Studio Save, Rename, Copy and Export.

## Design sample

A PDF or Word document imported as a starting design. It needs review and explicit data mappings before use as a finished template.

## Studio package

A `.sct-template` file containing a portable saved design and its assets. It does not contain the event session or printer settings.

## Layout box

An area that automatically arranges ordered text rows, optionally hides empty rows and adjusts spacing or font size.

## Preprinted reference artwork

An image visible in Studio to represent existing paper artwork. When marked as preprinted, it is omitted from generated PDFs.
