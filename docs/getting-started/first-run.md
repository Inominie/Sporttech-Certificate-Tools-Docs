# First run

On first launch, the app checks its local desktop backend, Typst PDF renderer, runtime folders, and saved configuration.

## Empty app state

The app can start without imported data. This is normal. The Event screen will show that no source is loaded, and the workflow status will stay incomplete until data is imported.

## Main sections

| Section | Purpose |
| --- | --- |
| **Event** | Load or refresh competition data. |
| **Quick Check** | Review imported Sporttech event data and warnings. |
| **Produce** | Generate PDF previews, save PDFs, and print. |
| **Settings** | Adjust runtime behavior and diagnostics. |
| **Certificate Studio** | Manage templates, placeholders, and layout. |

## Recommended first action

Start in **Event** and choose one source:

- **Online URL** for Sporttech online events.
- **Offline OVS** for a local OVS server on the event network.
- **File Import** for Sporttech Excel exports.

After importing data, open **Quick Check** before producing PDFs.
