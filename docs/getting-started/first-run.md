# First run

## Empty app state

A clean installation contains no competition data or user templates. Each new app session starts without a loaded event or manual corrections. Your saved templates, settings and saved or printed PDFs remain available.

## Main sections

| Section | Purpose |
| --- | --- |
| Event | Load or refresh a competition. |
| Quick Check | Inspect classes, entries, warnings and certificate corrections. |
| Produce | Choose output, template, scope, quantities and order; preview, save or print. |
| Certificate Studio | Create reusable templates, map data and check selected entries. |
| Settings | Set auto-refresh, language, storage and calibration; manage updates and diagnostics. |

The refresh icon in the top header is available throughout the competition app and Studio. For Excel events it asks you to select an updated workbook.

## Recommended first action

Follow the [basic workflow](basic-workflow.md). For an existing certificate design, save it as a PDF and use [Studio sample import](../certificate-studio/design-samples.md). A Studio template shared by another club uses a [different import action](../certificate-studio/sharing-templates.md).
