# Installing the beta

Download beta installers from the [download page](https://inominie.github.io/Sporttech-Certificate-Tools-Docs/download). New updater-enabled Mac releases are signed and notarized. Windows installers remain unsigned; the computer must permit their installation.

## macOS

1. Choose **Download for Mac** on the download page. The DMG works on both Apple Silicon and Intel Macs.
2. Open the DMG.
3. Drag **Sporttech Certificate Tools.app** into **Applications**.
4. Launch the app.

Older unsigned beta builds may show additional Gatekeeper warnings. Install the new signed application into Applications to establish the baseline for future in-app updates.

## Windows

1. Choose **Download for Windows** on the download page. Use the EXE installer for Windows x64.
2. Run the installer.
3. If Microsoft Defender SmartScreen appears, choose **More info > Run anyway** only when the build came from a trusted project source.
4. Launch **Sporttech Certificate Tools** from the Start Menu or desktop shortcut.

SmartScreen warnings are expected until the app is signed and has reputation.

## Clean install state

A new installation does not include competition data or personal certificate templates. Built-in starters are available in Studio. On first launch, the app opens empty. Import event data and choose or create a certificate template before producing PDFs.

If a current signed Mac installer is unexpectedly blocked, see [troubleshooting](../troubleshooting/common-issues.md#macos-blocks-the-app) before changing system security settings. For existing installations, prefer [in-app updates](../settings/checking-for-updates.md).
