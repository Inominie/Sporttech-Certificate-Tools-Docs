# Installing the beta

Download beta installers from the [public release page](https://github.com/Inominie/Sporttech-Certificate-Tools-Docs/releases). New updater-enabled Mac releases are signed and notarized. Windows installers remain unsigned; the computer must permit their installation.

## macOS

1. Download the current macOS DMG from the project owner or the beta release page.
2. Open the DMG.
3. Drag **Sporttech Certificate Tools.app** into **Applications**.
4. Launch the app.
5. If macOS blocks the app, open **System Settings > Privacy & Security** and allow the app to run.

Older unsigned beta builds may show additional Gatekeeper warnings. Install the new signed application into Applications to establish the baseline for future in-app updates.

## Windows

1. Download the current Windows installer from the project owner or the beta release page.
2. Run the installer.
3. If Microsoft Defender SmartScreen appears, choose **More info > Run anyway** only when the build came from a trusted project source.
4. Launch **Sporttech Certificate Tools** from the Start Menu or desktop shortcut.

SmartScreen warnings are expected until the app is signed and has reputation.

## Clean install state

A new installation does not include competition data or certificate templates. On first launch, the app opens empty. Import event data and choose or create a certificate template before producing PDFs.
