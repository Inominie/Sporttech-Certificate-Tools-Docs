# Support bundles

Support bundles are ZIP files for private beta diagnostics.

<figure className="app-screenshot">
  <img src="/Sporttech-Certificate-Tools-Docs/img/app/settings-diagnostics.png" alt="Settings screen with the Beta Diagnostics support bundle section visible" />
  <figcaption>The Beta Diagnostics area summarizes what support bundles include and what privacy checks matter before sharing.</figcaption>
</figure>

## What is included

A support bundle can include:

- App version and platform details.
- Runtime paths.
- Template diagnostics.
- Import metadata.
- Warnings.
- App configuration.
- Manual correction overrides.
- Print history.
- Active certificate CSV.
- Import data-map summary, when generated.

## Privacy review

Before sharing a bundle, review it carefully. It can contain:

- Participant names.
- Clubs or representing organizations.
- Classes.
- Placements.
- Scores.
- Local filesystem paths with usernames or event folder names.

Generated PDFs and uploaded template/source files are not copied into the ZIP, but metadata and referenced paths may still appear.

## Creating a bundle

Open **Settings** and click **Create Support Bundle**.

Share the bundle only through the approved beta support channel.
