# Certificates

## Select a template

Choose **Certificates** and a saved template for the selected category: Single, Synchronized or Team. Open Studio from the template control when it needs editing. Save your changes there before returning to Produce.

## Choose a scope

Choose the required entry, selected entries, class or available wider scope. Review the entry/page count and exclusions before printing. A template's category must match its entries; selecting a team template does not convert an individual entry into a team.

## Number of copies

**Copies** offers:

| Setting | Certificates generated |
| --- | --- |
| One per entry (default) | One for each selected single athlete, synchronized pair or team. |
| One per athlete | Single: 1; synchronized: 2; team: one per member. |

Team quantities use the reported member count, or the available roster when there is no reported count. The six possible name fields on a template do not determine team size. A reported team count can include members whose names are not supplied.

In per-athlete mode, open **Check or adjust quantities** to review automatic counts or enter an explicit quantity from 1 to 100 per entry. Clear an override or reset to automatic quantities to use the calculated count again. If the team size is missing or inconsistent, supply a quantity before generating the PDF.

Copies of an entry stay together in the PDF. They repeat the same certificate content; this option does not generate a different individual name on each team copy. A PDF is limited to 10,000 certificate pages. These controls do not affect class lists, calibration sheets or individual history reprints.

**Choose one copy in the printer dialog.** The PDF already contains the requested copies. Quantity selections are event-session choices, not part of the template; they reset for a different event or new session.

## Print order

Choose **First place first** or **Last place first**. Reversal happens within each class; it does not reverse the order of classes. Entries without a usable place follow the ranked entries. With one entry, there is no meaningful order to change.

Check the first and last pages after changing order, especially when using multiple copies.

## Warnings

Resolve missing mappings, unknown quantities or layout overflow before generating output. Inspect warnings about event data in Quick Check. If the template uses [preprinted-paper artwork](../certificate-studio/preprinted-paper.md), the PDF intentionally omits those images; load the matching paper.
