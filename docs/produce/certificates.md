# Certificates

Use **Certificates** when producing certificate PDFs from the active template.

<figure className="app-screenshot">
  <img src="/Sporttech-Certificate-Tools-Docs/img/app/produce-preview.png" alt="Certificate production view with all groups selected and a PDF preview ready" />
  <figcaption>Certificate mode renders the selected certificate scope through the active template before saving or printing.</figcaption>
</figure>

## Select a template

Confirm the selected template in the Produce template selector. Use **Open Studio** when the layout or placeholder mapping needs changes.

## Choose a scope

The certificate scope can target:

- All printable rows.
- One class or group.
- One athlete, pair, or team.

Entries removed in Quick Check are excluded from certificate output.

## Warnings

Open the warning summary when it reports warnings. Common warning types include missing template data, missing source values, or layout issues.
