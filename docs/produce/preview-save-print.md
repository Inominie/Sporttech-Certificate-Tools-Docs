# Preview, save, and print

## Preview

Preview creates a temporary PDF for the current data and output settings. Changing entries, template, copies or order can regenerate it. Wait for the current preview before acting; a previous PDF does not reflect later corrections automatically.

Studio's real-data canvas helps with design. A generated PDF checks the actual output, including font layout and page order. Images marked as already on preprinted paper are omitted from **all generated PDFs**, including previews.

A preview/test PDF is temporary even if you open it in another viewer. It is cleared with session cleanup unless explicitly saved or retained by a successful print submission.

## Save

Choose **Save PDF** to keep the generated document. Saved PDFs persist after restarting. If a file with the same name exists, review the overwrite/name conflict instead of assuming it was replaced. Use Open Folder to locate saved outputs.

Saving a PDF does not save unsaved Studio edits or make a transferable template. Use Studio Save and [template export](../certificate-studio/sharing-templates.md) for that.

## Print

You can print the current preview directly; saving first is optional. A successfully submitted desktop print job retains its PDF and records the print. Cancellation or failure does not count as a successful retained print. Submission confirms the operating system accepted the job, not that paper physically emerged.

When using [automatic certificate copies](certificates.md#number-of-copies), set the printer dialog to **one copy**. Use actual size/100% scale when matching preprinted paper and test [calibration](print-calibration.md) first.

## Open files

**Open PDF** opens the current output in an external viewer; **Open Folder** opens the output directory. External viewers and print dialogs may have their own scaling or copy settings. Check those before printing.

Saved and printed files count toward the configured storage limit. If storage is full, keep needed files elsewhere and remove unwanted outputs deliberately; the app does not automatically discard retained certificates to make room.
