# Preview, save, and print

Always preview before saving or printing.

  <img src="/Sporttech-Certificate-Tools-Docs/img/app/produce-preview.png" alt="PDF preview screen with Save, Print, Open, and Folder actions" />
  <figcaption>After preview generation, the save, print, open, and folder actions become part of the final production workflow.</figcaption>
</figure>

## Preview

Click **Preview PDF** to render the current selection. The preview confirms:

- Document type.
- Selected rows.
- Active template, for certificates.
- Approximate page count.
- Renderer health.

## Save

Click **Save PDF** when the preview is correct.

If a file with the same name already exists, the app asks whether to save a copy or overwrite the existing file.

## Print

Click **Print** after a preview has been saved. The app uses the operating system print flow. Direct silent printing is not currently implemented.

## Open files

Use **Open PDF** for the saved document or **Open Folder** for the output directory.
