# Manual corrections

Certificate corrections adjust presentation details without changing Sporttech results. They are local to the current event session and are not written back to Sporttech.

## Correct a selected row

Select a class and entry, then use the correction controls for names, clubs, team names or a certificate note. For synchronized names and clubs, separate the two athletes' values with `/` so individual and combined mappings can use them consistently.

Scores, placements and competition groups cannot be overridden here. Correct those in Sporttech, then refresh the event.

## Revert corrections

Use the revert/reset action for the relevant correction to return to the imported value. Refreshing the **same event** keeps corrections. Loading another event, importing a new file or restarting the app clears them. For a replacement export of the same event, use **Refresh current file…**.

A correction can intentionally remain different from a later source value. Check the overrides filter when reviewing unexpectedly different text.

## Remove rows from printing

Exclude entries or groups from the print selection when they should not receive certificates. This does not delete Sporttech results. Use the removed-items view to restore them. Review the selected scope in Produce before printing.
