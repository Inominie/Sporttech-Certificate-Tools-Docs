# Manual corrections

Manual corrections are used when imported Sporttech event data needs an operator adjustment before printing.

## Correct a selected row

1. Open **Quick Check**.
2. Select the athlete or team row.
3. Click **Correct Selected**.
4. Apply the needed correction.
5. Save the change.

Manual corrections are counted in the Quick Check overview and shown by the **Overrides** filter.

## Revert corrections

Individual corrections can be cleared from the correction panel.

To clear all manual corrections, open **Settings** and use **Revert Manual Corrections**.

## Remove rows from printing

Entries can be removed from print when a certificate should not be produced. Removed entries stay visible in Quick Check so the operator can audit what changed.
