# Groups and finals

## Class groups

Quick Check presents the competition classes and groups imported from Sporttech. Select a class to inspect its entries, warnings and available phases. You can exclude a group from printing and restore it later; this changes the print selection, not the competition structure.

## Merging groups

The current app does **not** merge or rename Sporttech groups or recalculate their placements. Earlier beta instructions described controls that have been removed. Make competition-structure or ranking changes in Sporttech and refresh the event.

## Final rows

Qualification and final results retain their source meaning. A final row is not permission to add its qualification score locally. When creating a result list, choose the required phase or qualification-and-final view. See [class lists](../produce/class-lists.md).

Check the class, phase, score and place together, especially when several rounds contain the same athletes.
