# Groups and finals

Quick Check helps verify how imported Sporttech event data is grouped into certificate classes and how final data is represented.

## Class groups

Imported event entries are grouped by certificate class. A class can be opened from the **Class Health** table.

Use group actions when a class name or grouping needs to be corrected before producing PDFs.

## Merging groups

When groups are merged, the app can recalculate placements. This behavior is controlled in **Settings > Review Corrections**.

If recalculation is turned off, athletes keep their imported or manually corrected place values after group changes.

## Final rows

The **Finals** filter shows entries marked as final results. Review them before producing certificates, especially when qualification and final scoring rules affect the printed total.
