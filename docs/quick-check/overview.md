# Quick Check overview

Use **Quick Check** to verify imported Sporttech event data before producing PDFs.

<figure className="app-screenshot">
  <img src="/Sporttech-Certificate-Tools-Docs/img/app/quick-check.png" alt="Quick Check screen showing event health cards and the Class Health table" />
  <figcaption>Quick Check gives the operator a full-screen readiness view before PDFs are produced.</figcaption>
</figure>

## What to check

The overview summarizes:

- Total imported event entries.
- Number of classes.
- Active warnings.
- Manual corrections.
- Removed rows.
- Final rows.
- The currently selected row.

## Class Health

The **Class Health** table groups imported event entries by class. Open a class to inspect its athletes, teams, or pairs in place.

Use the filters to focus on:

- **All** rows.
- **Overrides** with manual changes.
- **Removed** rows excluded from print.
- **Finals** rows.

The search field accepts athlete names, club names, and class labels.

## Details drawer

Selecting a row can show details such as summary data, routines, judges, and raw source data where Sporttech exposes it.
